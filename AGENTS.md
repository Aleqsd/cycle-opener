# Cycle & Opener

[Socle commun](../AGENTS.md) — ce document le complète pour ce plugin uniquement.

Guide statique par niveau pour les 21 jobs de combat et leurs classes de départ, tâche de référence `01a0ba04-1903-7c22-9c3b-e83ca4c6c525`. Le Mage bleu reste exclu, à la demande de l’utilisateur. Correction explicite du 19 septembre : schémas de cycle et d'ouverture, listes de priorités comme Icy Veins ; pas de conseil de prochain sort en temps réel. Seuls le job, le niveau et les conditions nécessaires à différer la proposition de synchronisation sont lus. Aucun suivi des cibles, jauges, sorts ou dégâts.

- `src/Core.cs` et `WhiteMage.cs` : règles BLM/WHM. `JobGuides*.cs` : autres fiches et conditions, avec cache par job/niveau/cibles. `Jobs.cs` : identités, classes, couleurs et sources. `JobActions.cs` : métadonnées factuelles générées par `tools/import-actions.py`, révision XIVAPI épinglée ; relancer après toute nouvelle référence à une action. `Plugin.cs` : services Dalamud. `Hud.cs` : cinq compositions. `tests/` : cas métier. `tools/Preview/` : rendu ImGui hors jeu. `preview/` : comparateur local.
- SDK .NET 10, Dalamud API 15. `build.ps1` compile puis exécute les contrôles ; `tools/render.ps1` produit les aperçus natifs. Les commandes effectivement validées sont consignées dans `docs/VALIDATION.md`.
- Panneau LMeter, couleurs des jobs éclaircies pour le petit texte ; feu et glace uniquement pour le Mage noir. Settings fixes. Cinq modes : Fiche express, Frise, Priorités, Deux sections, Ouverture. Lecture libre, pas de progression liée au combat.
- Une seule fenêtre de guide, avec Les deux / Cycle / Ouverture. Direction approuvée le 19 septembre : panneau discret sans barre de titre générique, en-tête intégré (job/niveau, repli, verrouillage, réglages, fermeture), ouverture en bandeau au-dessus du cycle. `GuidePanel.cs` porte la composition et les contrôles ; le contenu seul défile. Les répétitions sont regroupées, sans cacher les conditions ni les aptitudes intercalées. Les soins des soigneurs et les protections des tanks restent dans des sections dépliables distinctes. Fermer les réglages ne retire pas les contrôles du guide ; le verrouillage agit seulement sur la position et la taille.
- Niveau synchronisé lu sur le personnage ; choix manuel d'un autre niveau possible. Mono, 2 cibles et sélection exacte de 3 à 8 : les seuils concernent des ennemis regroupés. Les nouveaux jobs affichent « Départ pédagogique », jamais une promesse d’ouverture optimale. Conditions et ressources doivent rester explicites ; filtrer les actions verrouillées ne suffit pas à garantir une séquence réalisable.
- Actualisation via Framework.Update, aucun IO ni calcul natif lourd dans Draw. Icônes locales par ITextureProvider, aucune icône extraite incluse dans les binaires. Cache web d'icônes réservé aux aperçus locaux, ignoré par Git. Expressway facultative et non redistribuée.
- Une capture ImGui hors jeu ne prouve pas l'intégration FFXIV. Vérifier ensuite en jeu : niveau synchronisé, job/zone, reconnexion, popup après chargement et hors combat, fermeture, déplacement et restauration du panneau. Ne pas annoncer une publication ou un chargement effectif sans preuve.
- Livrable local dans `plugin/CycleOpener.dll`, paquet versionné dans `releases/`. Sources et releases dans Aleqsd/cycle-opener ; intégration du dépôt personnalisé confiée à la tâche de publication du socle.

- Choix utilisateur : Fiche express (affichage 1) par défaut, avec ouverture au-dessus dans le panneau intégré. Préserver les préférences déjà sauvegardées. L’icône originale est dans `assets/`, sa provenance dans `docs/ASSETS.md`.
- Dans un clone autonome, le socle parent peut être absent. Ce dépôt compile indépendamment ; appliquer alors les instructions locales disponibles sans créer un socle concurrent.

- Nom public et identité de chargement : Cycle & Opener / `CycleOpener`, dépôt `Aleqsd/cycle-opener`, commande `/cycle`. Le dossier local historique reste `astral-guide/` ; aucun déplacement implicite. Le nom et l’icône restent indépendants des jobs.
- Diffusion autorisée uniquement sur le GitHub d’Aleqsd et son dépôt personnalisé. Demande explicite : aucune PR ni soumission au catalogue officiel Dalamud ; ne pas activer son suivi.

- Panneau de consultation : actions d’ouverture par boutons, jamais par cases à cocher. Niveau et cibles regroupés, comportement et apparence secondaires. Fiche express en lignes de sorts compactes, deux rappels conditionnels visibles. Le clic manuel sur une étape ne suit aucune action du joueur.

Migration et clics natifs vérifiés dans `tools/Preview/PanelChecks.cs`.
