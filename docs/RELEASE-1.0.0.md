## Cycle & Opener 1.0.0

- Les 21 jobs de combat et leurs classes de départ ont leur fiche par niveau. Le Mage bleu reste prévu pour plus tard.
- Cycle, priorités et départ pédagogique réunis, avec icônes et noms des sorts du client français ou anglais.
- Nombre de cibles précis de 1 à 8, avec les seuils de zone adaptés au niveau.
- Rappels de soins pour les soigneurs, protections pour les tanks et sources propres à chaque job.

Les nouvelles ouvertures servent à apprendre le départ ; les variantes optimisées de raid restent dans les sources liées. Guide statique, sans lecture du combat ni lancement de sort.

Compilation et contrôles ImGui hors jeu validés. Cette version reste à essayer en jeu.

Installation : dépôt personnalisé habituel ou ZIP ci-dessous. Commande `/cycle`.
