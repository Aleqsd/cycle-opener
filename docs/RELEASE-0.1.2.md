# Cycle & Opener 0.1.2

- Boutons pour ouvrir le cycle, l’ouverture ou les deux. Chaque panneau se ferme indépendamment.
- Réglages réorganisés : niveau, cibles et présentation réunis ; mono/2/3+ accessibles directement.
- Fiche express plus compacte, avec deux rappels de priorité visibles et des infobulles enrichies.
- Ouverture plus lisible : flèches, repères sur les étapes commentées et bouton pour revenir au début.

Les préférences existantes sont conservées. Version expérimentale pour Dalamud API 15 ; rendu et interactions ImGui vérifiés hors jeu, intégration FFXIV à confirmer.
